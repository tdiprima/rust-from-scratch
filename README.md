# rust-from-scratch

Hands-on Rust learning through annotated lessons and reference material.

## Learning a Systems Language Without the Overwhelm

Most Rust tutorials either skip the hard parts or dump everything on you at once — ownership, lifetimes, traits, async — before you've written a single useful program. This repo breaks it into digestible lessons you can follow at your own pace.

## Lessons

| File | What it covers |
|---|---|
| `00-overview-and-installation.md` | What Rust is, installing rustup/Cargo, common commands, resources |
| `01-hello-rust.md` | First Cargo project, variables, functions, control flow, ownership, error handling |
| `02-guessing-game.md` | Build a number-guessing game with I/O, external crates, pattern matching |
| `03-todo-list-cli.md` | Core language concepts + build a CLI to-do list app (structs, enums, vectors, traits) |
| `syntax-reference.md` | Rust syntax explained through natural-language analogies |

## Getting Started

**Prerequisites:** Install Rust via [rustup](https://www.rust-lang.org/tools/install), which also installs Cargo.

```bash
rustc --version
cargo --version
```

**Try any snippet instantly (no install needed):**
Paste code into the [Rust Playground](https://play.rust-lang.org).
